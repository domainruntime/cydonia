# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

- Use GitHub private vulnerability reporting ("Security" tab → "Report a vulnerability") where it is enabled, or
- email **security@ekairos.dev** with a description, affected component/version and steps to reproduce.

We acknowledge reports within 3 business days and keep you informed until the issue is fixed. Please give us a reasonable time to remediate before any public disclosure.

## Supported versions

Only the latest release on the default branch (and what is deployed from it) receives security fixes.
